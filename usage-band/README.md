# usage-band

Полоса над полем ввода в Claude desktop и в терминале:

`↻ Сброс 02:41 │ 5 ч ▰▰▰▱▱ 58% │ 7 дн ▰▱▱▱▱ 21% │ Контекст ▰▰▱▱▱ 34%`

- **Сброс** — сколько осталось до сброса 5-часового лимита.
- **5 ч / 7 дн** — расход лимитов: зелёный до 60 %, жёлтый до 85 %, дальше красный.
- **Контекст** — заполнение окна контекста текущей сессии.

В desktop полоски рисуются SVG, в терминале — символами `█░`.
