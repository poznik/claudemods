# session-board

Панель «Сессии» рядом с чатом: активные сессии по всем проектам, без закрепления в сайдбаре.

**Статус: прототип.** Работает только в Windows.

- **Работают** — сессии, которые сейчас выполняют ход.
- **Ждут прочтения** — закончили, пока вы были в другой сессии. Пометка появляется только у сессий, в которых загружен этот мод.
- **Недавние** — пять последних остальных.

Клик по строке открывает сессию. Свёрнутая панель показывает счётчики `⟳ N  ● N`. Команда `/board` открывает панель заново.
