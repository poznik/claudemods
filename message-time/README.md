# message-time

Время над сообщениями в ленте Claude Code (desktop и терминал): мелкое тусклое
`14:32` у правого края над каждым твоим сообщением и над каждым текстовым блоком
ответа агента.
Сообщения не за сегодня подписаны с датой: `15.11 14:32`.

- Время старых сообщений берётся из файла транскрипта сессии, поэтому оно верное
  и после перезапуска.
- Время новых сообщений засекается, когда сообщение впервые появляется на экране.
- Работает только в сессиях Claude Code (вкладка Code, CLI). Обычный чат claude.ai
  мод изменить не может.
