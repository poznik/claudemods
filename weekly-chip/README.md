# weekly-chip

Метка `7д 96%` в строке под полем ввода, слева от названия модели: сколько
процентов недельного лимита уже израсходовано.

- Цвет: серый до 60 %, жёлтый до 85 %, дальше красный.
- Цифра обновляется после каждого ответа агента.
- Может отличаться на 1 % от кружка лимитов справа: метка берёт цифру из ответов
  API этой сессии, а кружок — с claude.ai, где учтены все сессии и устройства.
- Правее кружка метку не поставить: порядок элементов в этой строке задаёт
  приложение.
